Privacy policy

Waterline

Effective November 25, 2026

Waterline is a personal budgeting tool. It is built and used by one person, its owner, to manage their own bank and card accounts. It is not offered to anyone else, so the only person whose data it handles is the owner.

What data Waterline collects

  • Transactions from the owner's own accounts: date, amount, description and merchant.
  • Account details needed to sort those transactions: account name, type (such as checking or credit) and the last few digits of the account number.

Waterline reads this data through Plaid. It asks Plaid only for transaction data. It does not collect login credentials: the owner signs in to each bank through Plaid or the bank itself, and Waterline never sees the password.

How it is used

The data is used only to show the owner their own spending, income, bills and balances. The connection is read-only: Waterline cannot move money or make changes at the bank.

Where it is stored

  • Transactions are stored in a database file on the owner's own computer. There is no Waterline server and no cloud copy.
  • The keys that let Waterline fetch new transactions from Plaid are stored in the computer's encrypted keychain (macOS Keychain), not in files.

Sharing

Waterline does not sell, rent or share financial data with anyone, and does no advertising or tracking. Data leaves the owner's computer only in these cases, all at the owner's own choice:

  • Plaid, which retrieves the data from the bank. Plaid's handling is described in its End User Privacy Policy.
  • An AI assistant the owner uses to ask questions about their own finances. When the owner asks a question, the answers Waterline looks up are sent to that assistant under the owner's own account.

Keeping and deleting data

Data is kept until the owner deletes it. Disconnecting a bank in Waterline also removes the connection at Plaid, so no further data is fetched. Access can also be revoked from the bank's own security settings or through Plaid Portal.

Security

The database stays on a computer with full-disk encryption and a login password. Plaid connection keys are encrypted by the operating system. Imported bank records are kept write-once, so they cannot be edited after import.

Changes and contact

If this policy changes, the new version will be posted here with a new effective date. Questions can be sent through the owner's GitHub profile.
